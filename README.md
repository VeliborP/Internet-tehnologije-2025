# Internet Tehnologije – Demo Projekat

Ovaj projekat je razvijen kao deo predmeta **„Internet Tehnologije“** i predstavlja jednostavnu web aplikaciju baziranu na Java ekosistemu. Projekat demonstrira rad sa **Spring MVC arhitekturom**, server-side renderovanjem HTML stranica i osnovnom obradom podataka.

## Tehnologije korišćene u projektu

### Backend
- Java 17
- Spring Boot
- Spring MVC
- Spring Dependency Injection

### Frontend
- Thymeleaf
- HTML5 / CSS3 (osnovno)

### Baza podataka
- MySQL
- MySQL Connector/J
